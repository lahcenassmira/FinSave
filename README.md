# 💰 FinSave – Smart Financial Tracker & Auto-Savings App

**FinSave** is a full-stack fintech solution that helps users track spending, automate savings, and visualize financial trends — all in real time. Built for the Devopt Hackathon.

## 🚀 Tech Stack

- **Frontend**: Next.js 14 (App Router, TailwindCSS)
- **Backend**: expressjs + MongoDB + JWT Auth
- **APIs**: RESTful API (Users, Transactions, Savings)
- **Charts**: Chart.js with `react-chartjs-2`
- **Security**: JWT + bcrypt password hashing

---

## 🧠 Features

- 🔐 User authentication (register/login with JWT)
- 💸 Add, edit, delete transactions (income/expenses)
- 📈 Real-time charts & financial analytics
- 🪙 Auto-save based on roundups or percentage rules
- 🧮 Dashboard to view spending by category & time
- 📦 Modular, scalable architecture
